# tp7ls

Language server (LSP) для Turbo Pascal 7.0. Только TP7: диалекты Delphi, Free Pascal и Windows-код Borland Pascal
не поддерживаются.

## Что умеет

- **Форматирование** в одном фиксированном стиле, без опций (образцы: `testdata/polsk_formatted.pas`,
  `testdata/option_formatted.pas`). Регистр идентификаторов приводится к написанию в объявлении, в том числе для
  System, Crt, Graph и модулей из TPU. Строки длиннее 120 символов переносятся.
- **Диагностики**: синтаксические ошибки; неизвестные идентификаторы, модули и `{$I}`-файлы; повторные объявления;
  подпрограммы и методы без реализации; ошибки типов (значения вне диапазона, условие не `Boolean`, число и типы
  аргументов, не переменная на месте `var`-параметра, ...); неиспользуемые переменные, константы, типы и модули
  (серым). Чего сервер не понял, о том он молчит: ложных срабатываний быть не должно.
- **Навигация**: definition, declaration, typeDefinition, implementation, references, подсветка вхождений, rename,
  иерархия объектных типов, символы документа и проекта.
- **Подсказки**: hover (на операторе, скобке и `^` — тип выражения), автодополнение, signature help, inlay hints
  (имена аргументов, типы констант, имя подпрограммы после её `end`), semantic tokens.
- **Исправления** (code actions): удалить неиспользуемое объявление или модуль, исправить опечатку в имени, добавить
  недостающую реализацию.
- **Модули без исходников**: TPU и TURBO.TPL читаются напрямую. Для перехода к определению сервер генерирует
  заглушку с interface-частью модуля.
- **Условная компиляция** (`{$IFDEF}`, выключенные ветки серым) и **`{$I файл}`**.

## Сборка

Нужен Free Pascal 3.2.2. Проверено на Linux x86_64.

```
make            # build/tp7ls
```

## Подключение к редактору

`tp7ls` — LSP через stdin / stdout, без аргументов (`tp7ls --version` печатает версию).

- **Neovim** — плагин в `nvim/` (установка и настройки: [nvim/README.md](nvim/README.md)).
- **Другие редакторы**: запускать `tp7ls` для `*.pas`, корень проекта — папка с исходниками. Редактор должен
  открывать файлы в cp866 и сохранять с CRLF: сервер получает и отдаёт текст в UTF-8, перекодирует редактор.

Опции (`initializationOptions`):

| Опция | По умолчанию | Что задаёт |
|---|---|---|
| `tp7Dir` | `$TP7_DIR` | Папка Turbo Pascal: `TURBO.TPL` ищется в ней и в её `BIN`, модули — в `UNITS` |
| `stubDir` | `$TP7LS_STUB_DIR`, иначе `~/.cache/tp7ls/stubs` | Куда писать заглушки модулей из TPU |
| `typeDiagnostics` | `true` | Ошибки типов; `false` — только имена |
| `inlayHints` | `{"parameters": true, "constants": true, "endLabels": 25}` | Какие inlay hints показывать; `endLabels` — минимальная длина подпрограммы в строках (0 — не показывать) |

Модули ищутся в папке файла, во всём проекте (в любой подпапке), в `UNITS` и самой папке `tp7Dir`, в `UNITS`
рядом с `BIN`, где лежит `TURBO.TPL`. Без `TURBO.TPL` имена из System, Crt, Dos и других стандартных модулей
неизвестны.

## Ограничения

- `^C'текст'` (управляющий символ перед строкой) и `Mem[сегмент:смещение]` / `Port[...]` пока дают
  синтаксическую ошибку.
- Вариантные записи показываются плоско; `packed` и `far` в TPU не хранятся; inline-байты не декодируются.
- Не проверяются: диапазон шестнадцатеричных литералов, типы в инициализаторах типизированных констант; `{$V-}`
  игнорируется; rename через `{$I}`-файлы отклоняется.

## Разработка

- `src/`, `tests/` — сервер на Free Pascal и его тесты (FPCUnit).
- `python/` — исходный прототип на Python. Заморожен; протокольные тесты из него (`python/test_*.py`) — тесты
  сервера (`make prototest`).
- `nvim/` — плагин для Neovim.
- `tools/compare.py` — сверка с прототипом; `tools/pyproto.py` — протокольные тесты против `build/tp7ls`.

```
make test                  # тесты FPCUnit на образцах из testdata/
make prototest             # протокольные тесты против build/tp7ls
make leaks                 # тесты FPCUnit под heaptrc: утечек быть не должно
make pytest                # тесты замороженного прототипа (справочно)
make compare FILES="testdata python/samples"
```

Правила и устройство кода — в [CLAUDE.md](CLAUDE.md).
